# Starlight: The Vault Heist

A browser-based 2D platformer built entirely in HTML5 Canvas and vanilla JavaScript — no game engine, no external libraries, no audio files.

## The Story

A museum has been robbed. Three ancient treasures — the **Star Compass**, the **Moonstone Shard**, and the **First Star Tablet** — are gone, taken by a shadowy figure known only as **The Vault**. The police call in the only one who can get them back: **Starlight**.

## About Starlight

Starlight is an original character who switches between two forms mid-mission:

- **Cape + Hood** — flies, fires eye-lasers, throws a star projectile
- **Suit + Tie** — fights up close like an acrobat, using kicks

*(Loosely inspired by Marvel's Moon Knight — hence the dual-identity, dual-costume mechanic.)*

## Features

- A full scrolling level: city streets → a swimmable lake → floating platforms → rooftops → a boss arena
- Two distinct combat movesets, each with cooldowns and hit feedback
- A boss fight against The Vault, with his own health bar and projectile attacks
- An animated intro cutscene (skippable) and a full ending sequence
- Background music and sound effects — all synthesized in code
- A title screen, win/lose states, and a "Play Again" reset

## Controls

| Key | Action |
|---|---|
| Arrow keys | Move |
| Space / Enter | Jump (Suit form) · Fly, hold to rise (Cape form) · Swim up in water |
| Z | Attack — kick (Suit form) or eye-laser (Cape form) |
| C | Throw the star — works in either form |
| V | Switch costume |
| Mouse click | Skip (intro/outro) · Play · Play Again |

## Tech Stack

- HTML5 Canvas
- Vanilla JavaScript — no frameworks, no libraries
- Web Audio API for synthesized music and sound effects

## Run It Locally

1. Clone this repo
2. Open `index.html` in a browser — or use a tool like VS Code's Live Server extension for auto-reload while editing
